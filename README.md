# Pranay Gavaskar — Digital Marketing Portfolio

Personal portfolio website — Digital Marketing & Performance Marketing (Fresher).
Built with plain HTML/CSS/JS, no build step needed. Every file sits in a single
flat folder — no subfolders — so there's nothing that can go wrong with a
folder-drag-and-drop upload on GitHub.

## Files (all in one folder — keep it this way)

```
index.html
resume.pdf
meta-ads-campaign.pdf
google-ads-search-campaign.pdf
ga4-analytics-report.pdf
gtm-ga4-tracking.pdf
looker-studio-dashboard.pdf
README.md
```

## Live pe daalne ka tarika (GitHub Pages) — step by step

1. Apne repo (`pranay-gavaskr-potfolio`) ke root page pe jao.
2. **Sab kuch jo pehle se hai use select karke delete kar do** (purane attempts se
   koi leftover/mismatched file na rahe), aur commit kar do.
3. Root page pe **"Add file" → "Upload files"** pe click karo.
4. Is zip ko extract karo apne computer pe, aur us extracted folder ke **andar** jaake
   saari **7 files ko individually select** karo (Ctrl/Cmd+A se sab select karke) —
   **folder ko khud drag mat karna**, sirf files ko select/drag karo. Ye step sabse
   zaroori hai: folder drag-drop browser ke hisaab se kaam nahi karta, isliye is baar
   sirf loose files upload karo.
5. Neeche **"Commit changes"** pe click karo.
6. Repo ke root page pe check karo — 8 items dikhne chahiye (7 files + README), koi
   bhi folder icon nahi dikhna chahiye. Agar koi folder dikh raha hai to wahi
   dobara problem create karega.
7. **Settings → Pages** me jao, confirm karo Source: **Branch: main, Folder: / (root)**.
8. 1-2 minute wait karo, phir site check karo:
   `https://pranaygavaskar.github.io/pranay-gavaskr-potfolio/meta-ads-campaign.pdf`
   — agar ye seedha khul jaaye (PDF dikhe), to poori site sahi kaam karegi.

## Note

- Koi subfolder nahi hai ab — sab kuch root me flat hai, isliye future me resume ya
  koi PDF update karna ho to bas usi naam ki file replace kar dena, sidha root me.
- Agar kabhi naya project PDF add karna ho, usse bhi root me hi rakhna aur
  `index.html` me uska naam jahan zaroorat ho wahan likh dena.
